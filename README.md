# 统一账户交易配置说明

为了确保交易功能正常使用，请完成以下配置：

1. **将账户切换为「统一账户模式」**。
2. 切换完成后，**重新创建交易 API**。
3. 创建交易 API 时，务必勾选：
   - **开启统一账户交易**
5. **带单交易API**无法使用统一账户交易接口，只能使用U本位交易接口。
6. 完成以上设置后，即可正常进行交易。
